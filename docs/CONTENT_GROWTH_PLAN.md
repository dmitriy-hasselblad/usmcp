# SM VIA content growth plan

## Purpose

Build an original, practical resource library for U.S. healthcare professionals. Each guide should help a reader make a real career decision and connect naturally to job search, Job Alerts, a professional profile, or the CV Builder.

## Editorial safeguards

- Use an official primary source for licensing, immigration, regulation, salary, and clinical-policy claims.
- Add a visible source list and a clear limitation notice to high-stakes guides.
- Do not copy employer job descriptions, provider content, or competitor articles.
- Attribute an author or SM VIA editorial review before publishing material guidance.
- Review regulated content at least every six months and after a material rule change.

## Operating cadence

- Publish one thoroughly reviewed guide each week.
- Create one LinkedIn post, one Instagram carousel, and one concise newsletter section from every guide.
- Track impressions, organic clicks, guide-to-job-search clicks, CV Builder starts, Job Alert opt-ins, and employer leads.
- Improve existing guides before increasing the publishing pace.
